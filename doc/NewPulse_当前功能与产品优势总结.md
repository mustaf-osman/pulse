# NewPulse 当前功能与产品优势总结

## 一、产品一句话介绍

**NewPulse 是一个面向多行业场景的 AI 桌面工作台。**

它不是单纯的聊天机器人，而是把 **行业知识、客户/课题资料、长期记忆、语音交互、文献分析、业务跟进、数据看板和云端授权** 组合在一起，让用户可以在自己的行业场景里直接使用 AI 完成工作。

---

## 二、当前已经具备的核心功能

| 功能模块 | 已有能力 | 用户价值 |
|---|---|---|
| 多行业工作台 | 支持电商、科技、制药医药、教育、法律、健身、食品、农业、宠物、旅游、二手车、餐饮、跨境、人力资源等行业包 | 不同行业有不同助手身份、提示词、资料字段和工作流，不是通用 AI 硬套 |
| 行业切换与隔离 | 每个行业的客户/课题、记忆、会话、知识上下文相互隔离 | 用户切换行业时不会混淆数据，电商客户不会跑到医药课题里 |
| 行业专属 AI 助手 | 不同行业自动切换助手身份，例如电商助手、科技助手、药学科研学习助手 | AI 回答更贴合行业语境，减少“答得很泛”的问题 |
| 行业能力面板 | 展示行业对象、专家角色、可用技能、行业工作流，点击即可进入对应 AI 分析 | 用户不用会写复杂提示词，点按钮就能进入专业任务 |
| 行业快捷动作 | 每个行业有高频动作，比如复购召回、POC 推进、文献精读、课题孵化、实验设计 | 把 AI 从“聊天”变成“可执行的工作按钮” |
| 客户/课题资料管理 | 支持保存客户、店铺、B2B 线索、科研课题等行业对象资料 | AI 可以基于已有资料持续分析，不是每次都从零开始 |
| 今日首页工作台 | 首页显示行业专属入口、今日简报、待推进事项、快捷任务 | 用户一打开软件就知道今天该做什么 |
| 数据与跟进看板 | 支持客户/课题数量、今日更新、本周新增、待推进、停滞风险等统计 | 适合老板、负责人、销售、课题组管理当前进度 |
| 长期记忆系统 | AI 可以沉淀用户偏好、客户资料、课题背景、事实信息 | 让 AI 越用越懂用户，不只是一次性问答 |
| 行业知识注入 | 行业知识文件可按当前问题相关性注入上下文 | 回答时能结合行业资料、规则和经验，不只是模型裸答 |
| 热点/雷达能力 | 电商、科技等行业可结合热点、趋势、商机线索做分析 | 适合选品、内容、市场机会、科研选题等场景 |
| 语音交互功能 | 已接入本地 Whisper 语音识别，可进行语音输入和本地语音能力扩展 | 用户可以直接说话，不用一直打字，适合桌面工作流和真实办公 |
| 本地桌面端 | Electron 桌面应用，本地 Node 服务，支持本地数据、文件、语音能力 | 比纯网页 AI 更贴近电脑工作场景，后续可扩展文件和自动化能力 |
| 云端商业授权 | 已有账号登录、设备绑定、功能权限、额度限制、管理员后台 | 具备软件商业化、SaaS 授权、按功能收费的基础 |
| 权限与额度控制 | 云端可控制账号功能、每日额度、设备绑定、订阅有效期 | 后续可以区分免费版、专业版、企业版 |
| 管理员后台 | 管理用户、订阅、权限、设备、额度、强制退出 | 方便正式对外卖软件，而不是只有本地 demo |
| 行业默认会话 | 每个行业有自己的默认会话线程 | 行业上下文长期保留，避免混乱 |
| 设置与行业管理 | 可在设置中启用/切换行业 | 用户可按自己的业务选择行业模式 |

## 三、当前重点行业能力

### 1. 制药医药：药学科研学习工作台

这是目前最有差异化、最像独立产品的方向。

#### 已有功能

| 模块 | 功能 |
|---|---|
| 文献精读室 | 粘贴论文摘要或片段，AI 帮助拆解研究背景、科学问题、方法、结果、结论、证据链 |
| 学生版解释 | 把复杂药学/生命科学概念讲成学生能理解的版本 |
| 证据/机制链整理 | 可整理疾病、靶点、药物、指标之间的关系 |
| 课题孵化器 | 输入疾病、靶点、药物或方向，生成研究方向、科学假设、路线图和风险 |
| 实验设计台 | 输出教学/组会讨论级实验设计，包括变量、对照、模型、指标、数据分析思路 |
| 合规边界提醒 | 强调只用于学习、教学、科研训练，不输出临床诊疗或危险实验执行细节 |
| 课题资产管理 | 将科研课题作为资产保存，支持课题资料、负责人/导师、下次推进、研究备注等 |
| 药学知识地图 | 覆盖药理学、药物化学、药剂学、药代动力学、毒理学、临床前研究、ADMET 等方向 |
| 输出模板 | 文献精读模板、课题开题模板、实验设计模板 |

#### 价值

- 适合本科生、研究生、老师、科研人员、实验室团队。
- 可以辅助学生读论文、找课题、整理实验思路。
- 比普通 AI 更聚焦药学科研训练场景。
- 有明确安全边界，不做医生诊疗，不做危险实验指导。

#### 对外可说

> NewPulse 医药科研版可以帮助学生和课题组完成文献精读、课题孵化、实验设计和科研资料整理，是一个药学科研学习与训练工作台。

## 四、NewPulse 的核心优势

### 1. 不是普通聊天机器人，而是行业工作台

普通 AI 只能聊天，用户每次都要重新说明背景。

NewPulse 的优势是：

- 有行业身份
- 有行业资料
- 有行业字段
- 有行业按钮
- 有行业记忆
- 有行业看板
- 有行业流程

所以它更像一个可以长期使用的工作系统。

---

### 2. 多行业可扩展

现在已经有多个行业包：

- 电商
- 科技
- 制药医药
- 教育
- 法律
- 健身
- 食品
- 农业
- 宠物
- 旅游
- 二手车
- 餐饮
- 跨境
- 人力资源

这说明 NewPulse 不是单一行业工具，而是可以持续扩展成：

> AI 行业工作台平台。

---

### 3. 医药文献和科研功能差异化强

药学科研版是非常重要的亮点。

它可以覆盖：

- 文献精读
- 论文结构拆解
- 专业术语解释
- 机制链整理
- 证据表
- 课题方向生成
- 研究假设生成
- 实验设计框架
- 合规边界提醒
- 知识地图学习

这个方向比普通销售 CRM 更高级，也更适合高校、学生、老师、科研团队。

---

### 4. 语音交互是重要优势

NewPulse 已经接入本地 Whisper 语音能力。

这意味着它不只是文字输入工具，还可以走向：

- 语音提问
- 语音记录
- 会议/课堂/讨论后的内容整理
- 口述生成文档
- 口述生成课题思路
- 口述让 AI 分析客户/课题
- 后续扩展语音朗读和语音控制

对用户来说，语音功能有三个优势：

| 优势 | 说明 |
|---|---|
| 更自然 | 用户可以像和助理说话一样使用 AI |
| 更高效 | 不需要打长文本，适合临时想法、会议后整理 |
| 更像桌面助手 | 语音 + 桌面端结合，产品感比网页聊天强 |

对外可以说：

> NewPulse 支持本地语音识别，用户可以通过语音与行业 AI 助手交互，让 AI 更像一个真正的桌面工作伙伴。

---

### 5. 有本地桌面端优势

NewPulse 是 Electron 桌面软件，不是普通网页。

优势：

- 更贴近用户日常电脑工作
- 可以保留本地数据
- 可以接入本地语音模型
- 后续可以扩展文件读取、代码处理、屏幕理解、桌面自动化
- 企业用户接受度更高

---

### 6. 有长期记忆能力

NewPulse 可以保存长期记忆，例如：

- 用户偏好
- 客户关注点
- 课题背景
- 历史事实
- 行业经验
- 常用输出格式

这让它不是一次性问答，而是越用越懂用户。

---

### 7. 有数据看板和管理价值

它不只是“问 AI”。

它还能显示：

- 当前客户/课题数量
- 本周新增
- 今日更新
- 待推进事项
- 停滞风险
- 行业记忆数量
- 行业知识数量

这让老板、负责人、老师、课题组可以用它做管理。

---

### 8. 有商业授权后台

NewPulse 已经具备商业化基础：

- 用户账号
- 登录授权
- 设备绑定
- 功能权限
- 每日额度
- 订阅有效期
- 管理员后台
- 强制退出
- 权限配置

这很关键。

很多 demo 只能本地跑，但 NewPulse 已经可以往正式收费软件走。

## 五、适合对外展示的产品亮点话术

### 简短版

> NewPulse 是一个多行业 AI 桌面工作台，支持电商、科技、医药科研等多个行业场景。它不仅能聊天，还能管理客户/课题资料、保存长期记忆、生成行业方案、提供数据看板，并支持本地语音交互和云端商业授权。

### 医药版

> NewPulse 医药科研版面向药学本科生、研究生、老师和实验室团队，提供文献精读、课题孵化、实验设计和药学知识地图。用户可以粘贴论文摘要，让 AI 拆解论文结构、解释专业术语、整理证据链，并生成可讨论的研究方向和实验设计框架。

### 商业版

> NewPulse 已经具备正式商业化基础，支持账号登录、设备绑定、功能权限、额度控制和管理员后台，可以按行业、按功能、按账号进行授权销售。

### 语音版

> NewPulse 支持本地语音识别，用户可以通过语音直接向 AI 提问、记录想法、整理客户或课题信息，让 AI 更像一个常驻桌面的工作助理。

## 九、面向老师沟通的升级方向简版：NewPulse 智能体操作系统大脑

### 1. 项目定位

NewPulse 目前是一个 **多行业 AI 桌面工作台**，已经具备多行业助手、长期记忆、语音交互、文献精读、课题孵化、实验设计、数据看板和云端授权等能力。

下一步可以将它升级为：

> **面向 Linux 底层环境的智能体操作系统大脑。**

也就是说，Linux 作为底层系统，NewPulse 作为 AI 大脑，负责理解任务、调用工具、连接 API、本地文件、行业知识和模型服务。

### 2. 核心思路

整体架构可以理解为：

```text
Linux 底层系统
  ↓
NewPulse 智能体大脑
  ↓
行业能力包 / 长期记忆 / 权限控制 / 任务调度
  ↓
本地工具 / API / 文件系统 / 模型服务 / 语音交互
```

NewPulse 不只是聊天，而是一个可以调度工具、执行任务、沉淀知识的 AI 中枢。

### 3. 现在已经有的基础

| 已有能力 | 说明 |
|---|---|
| 多行业工作台 | 已支持电商、科技、制药医药、教育、法律等多个行业方向 |
| 医药科研功能 | 已有文献精读、课题孵化、实验设计、药学知识地图 |
| 长期记忆 | 可以保存用户偏好、客户资料、课题背景和行业知识 |
| 语音交互 | 已接入本地 Whisper 语音识别，支持语音输入 |
| 桌面端基础 | 已有 Electron 桌面应用和本地 Node 服务 |
| 行业数据隔离 | 不同行业的客户/课题、记忆、会话可以隔离 |
| 云端授权后台 | 已有账号、设备绑定、功能权限和额度控制基础 |

### 4. 还缺的核心能力

| 缺口 | 说明 |
|---|---|
| Agent Core | 需要把现有聊天、行业包、记忆、工具统一成一个智能体核心 |
| 工具调用层 | 需要支持文件读写、文档解析、Shell 命令、API 调用、浏览器操作 |
| Linux 运行时 | 需要适配 Linux 后台服务、Docker/systemd 部署 |
| 权限与安全机制 | 需要工作目录白名单、命令限制、操作确认、日志审计 |
| 任务编排能力 | 需要支持多步骤任务，例如读取文献、分析、生成报告、保存文件 |
| 模型适配层 | 需要支持云端 API、本地 Ollama/vLLM 等模型 |

### 5. 建议的第一阶段目标

第一阶段不要直接做完整操作系统，而是先做：

> **NewPulse Agent Core for Linux**

核心功能包括：

- 通过 API 提交任务
- 读取和保存文件
- 解析文档/PDF
- 调用行业能力包
- 调用长期记忆
- 生成 Markdown/报告
- 执行受限命令
- 记录任务日志
- 加入权限和安全控制

### 6. 项目优势

NewPulse 的优势在于：

1. **不是从零开始**
   - 已有桌面端、本地服务、行业包和记忆系统。

2. **行业场景明确**
   - 尤其是医药科研方向，已有文献精读、课题孵化、实验设计等功能。

3. **语音交互已经接入**
   - 可以作为未来智能体操作系统的人机入口。

4. **具备商业化基础**
   - 已有云端授权、账号管理、设备绑定、功能权限和额度控制。

5. **适合扩展成平台**
   - 行业包可以升级为不同的 Agent Skill Pack，后续可接入更多行业和工具。

### 7. 简短总结

NewPulse 可以从现在的 **多行业 AI 桌面工作台**，逐步升级为 **基于 Linux 的智能体操作系统大脑**。

它的核心价值是：

> 让 AI 不只是回答问题，而是能够在安全权限下调用工具、连接 API、处理文件、理解行业知识、执行任务并沉淀结果。

第一步建议先建设 **Agent Core + 文件/文档工具 + API 接口 + Linux 运行时**，再逐步扩展到浏览器控制、本地模型和完整任务编排。
