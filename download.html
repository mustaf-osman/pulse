FAQ

常见问题

下载后弹「Windows 已保护你的电脑」怎么办？

当前版本暂未做代码签名，Windows SmartScreen 会拦下未知发布者。点击弹窗中的「更多信息」，再点「仍要运行」即可。代码签名证书我们正在申请中。

客户数据存在哪里？会被上传吗？

所有客户、跟进、对话数据都存在你电脑的 %APPDATA%\Pulse 本地目录。Pulse 不会主动上传任何内容。AI 功能调用大模型时只会发送你当前对话的必要片段，不会发送完整客户库。

免费吗？要联网吗？

软件本身免费下载和使用。AI 功能需要你提供自己的 API key（DeepSeek / OpenAI / 通义等），消耗的 token 费用由你自己的密钥承担，Pulse 不抽成。无 AI 功能时也能离线管理客户。

怎么更新到新版本？

Pulse 每次启动会自动检测新版，发现后自动后台下载，下载完会询问你是否立即重启安装。也可以手动从本页下载最新安装包覆盖安装。

支持 macOS 和 Linux 吗？

当前只有 Windows 版。macOS 和 Linux 在路上，进度会在本站更新。

能多人协作吗？我团队有几个人

当前是单机版本，每个人在自己电脑上独立使用。多人协作（共享客户库、团队权限）在产品 roadmap 里，预计后续版本支持。
